# SUPER ADMINISTRATEUR DE LA PLATEFORME (is_superuser = true)

## OBJECTIF

Le Super Administrateur est l'administrateur de la plateforme SaaS.

Il ne représente **aucune entreprise** et **aucun magasin**.

Il est responsable de l'administration globale de la plateforme, du support client, de la maintenance et de la supervision.

Le Super Administrateur est identifié par :

```text
is_superuser = true
```

Il ne dépend pas du système :

```text
Membership
↓
Company
↓
Role
↓
Permissions
```

Son accès est accordé directement par le système.

---

# SCOPE

```text
PLATFORM
```

Le scope `PLATFORM` est supérieur aux scopes :

* COMPANY
* STORE

Il permet de gérer l'ensemble de la plateforme SaaS.

---

# RESPONSABILITÉS

Le Super Administrateur peut :

✓ gérer toutes les entreprises

✓ consulter toutes les données

✓ gérer les utilisateurs de la plateforme

✓ gérer les abonnements

✓ gérer les plans SaaS

✓ gérer la facturation

✓ gérer les paiements

✓ gérer les paramètres globaux

✓ gérer les modules disponibles

✓ consulter les journaux d'audit

✓ envoyer des notifications globales

✓ effectuer la maintenance

✓ assister les clients

✓ surveiller la santé de la plateforme

# LIMITES

Même s'il possède tous les accès techniques, le Super Administrateur ne doit pas intervenir dans l'activité métier quotidienne d'un client.

Il ne doit pas :

✗ effectuer des ventes

✗ ouvrir une caisse

✗ gérer un stock comme un employé

✗ agir comme un Manager ou un Caissier

En cas d'assistance, il doit utiliser le mode d'impersonation afin que toutes les actions soient tracées.

---

# TABLE UTILISATEUR

Le Super Administrateur est identifié par :

```text
users

uuid
email
password
is_superuser
is_active
```

Exemple :

```text
is_superuser = true
```

Aucune entrée n'est requise dans :

* memberships ;
* roles ;
* role_permissions.

---

# ROUTES

Le Super Administrateur accède à un espace dédié.

```text
/admin
```

ou

```text
/platform
```

Les utilisateurs des entreprises n'ont jamais accès à ces routes.

# HIÉRARCHIE DES ACCÈS

```text
PLATFORM

Super Administrateur

↓

COMPANY

Owner

Company Admin

↓

STORE

Manager

Stock Manager

Cashier

Accountant
```

Le Super Administrateur est le seul utilisateur ayant un scope `PLATFORM`. Les utilisateurs des entreprises utilisent exclusivement les scopes `COMPANY` ou `STORE`.
